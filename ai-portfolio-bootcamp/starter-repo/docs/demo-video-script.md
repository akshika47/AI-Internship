# Demo video script

> Total 3 minutes. Record with audio. Nobody watches a directory listing -
> do not start with a tour of the repo.

## 0:00-0:30 - The problem (30s)

> Open on the problem, not on you and not on the code.

<Script it word for word. Name the person, the task, and the cost.>

*"Priya leads support at a 30-person SaaS company. Every morning she hand-tags
60 overnight tickets. It takes 50 minutes, and about twice a week an urgent
ticket slips through because it was worded politely."*

## 0:30-2:00 - The demo (90s)

> Live, on real input. Show one thing failing gracefully - it is more convincing
> than a flawless run.

| Time | On screen | You say |
| --- | --- | --- |
| 0:30 | Sample tickets | |
| 0:50 | One command runs | |
| 1:10 | Output with confidence | |
| 1:30 | A low-confidence record escalating | |

## 2:00-2:45 - Results (45s)

> The numbers from your eval report. Before and after. Say the method in one
> line: "40 cases I labelled by hand."

## 2:45-3:00 - What is next (15s)

> One sentence on the honest limit, one on what you would build next.

---

**Recording checklist**

- [ ] Audio is clean. Bad audio loses more viewers than bad video.
- [ ] Font size readable at 720p.
- [ ] No credentials, no customer data, no personal email on screen.
- [ ] Under 3:00. Cut ruthlessly.
