# Operations & AI Associate, Brightpath Logistics (fictional sample job ad)

Hybrid, London · £34,000 to £40,000

Brightpath runs same-day delivery for 300 independent shops. We're hiring someone from
operations who wants to bring AI into how our depots run.

## What you'll do
- Own the daily exceptions report for late and failed deliveries, and cut the time it takes.
- Build simple automations with Zapier and Python to remove manual steps for depot teams.
- Pilot an AI assistant that drafts customer updates for delayed orders, and measure it.
- Write clear guides and train depot coordinators on new tools.

## What we need
- Experience in logistics, delivery or warehouse operations.
- Hands-on automation with Zapier, Make or n8n.
- Some Python for data work (pandas is enough).
- Clear writing for non-technical colleagues.

## Nice to have
- SQL.
- Has used an LLM API in a project.
