# Replying to emails

## Rules
1. **Match their tone.** Formal stays formal; a quick note gets a quick note.
2. **Under 120 words.** If it needs more, it needs a call: suggest one.
3. **Answer their question in the first line.** Context after, not before.
4. **End with one clear ask or next step**, with a day if there is one.
5. **Never promise anything the thread doesn't support**: no dates, prices or commitments
   the user hasn't already made. Mark anything you'd need them to confirm as [check].
6. Sign off as the user would: if the thread shows their sign-off, reuse it.
