# Writing research briefs

## Rules
1. **Every claim names its source** in brackets, e.g. (Smith, 2026) or (article.md). No source, no claim.
2. **Say "unknown" instead of guessing.** If the sources don't answer something the reader
   will ask, list it under "Gaps".
3. **Separate what the sources say from what you think.** Your view goes in "So what", last.
4. **Lead with the answer**: the first line is the one thing the reader must know.
5. One page: about 300 words.

## Output
```
**Bottom line:** one sentence
## What the sources say
- claim (source)
## Gaps
- ...
## So what
- ...
```
