The shape of an engagement


              SECURE                    START                       DELIVER                      CLOSE
            the deal          ->      the client            ->      the work            ->       it out
          (commercial)                (intake)                  (delivery)                     (handover)




Four stages. Each has a small number of jobs and a template for each job. Do them in order.




Stage 1: Secure the deal

Turn interest into a clean, signed, paid-for engagement.


    STEP                      DO THIS                                                                                               TEMPLATE


    Propose                   Send a tailored proposal built around how this client works                                           01 Consulting Proposal


    Contract                  Issue the SOW for signature; keep it general, specifics live in the internal plan                     02 Statement of Work


    Confirm                   Send the engagement letter so they know exactly what happens next                                     03 Engagement Letter


    Invoice                   Issue the deposit invoice                                                                             05 Invoice, 20 Billing SOP



Gate: the deposit clears before delivery begins. Hold the dates, do not promise them, until it does.




Stage 2: Start the client

Understand this client deeply enough that the work is built around them, not around a generic template.


    STEP                        DO THIS                                                                           TEMPLATE


    Run intake                  Follow the intake steps so nothing is dropped between people                      06 Client Intake SOP


    Discover                    Send the discovery questionnaire; learn how the team actually works               08 Discovery Questionnaire


    Map                         Capture their current process and the people who matter                           07 Process Mapping, 10 Stakeholder Map


    Plan                        Turn what you learned into a project plan                                         11 Project Plan


    Kick off                    Run a clean first session                                                         09 Kickoff Agenda

Stage 3: Deliver the work

Steady, visible, well-recorded delivery, with no surprises.


    STEP                             DO THIS                                                                    TEMPLATE


    Run sessions                     Deliver each session, record it, hand over materials within 24 hours       12 Meeting Agenda, 13 Meeting Notes


    Track                            Keep risks and issues in view, every week                                  16 RAID Log


    Report                           Send a short, honest status update on a regular rhythm                     14 Status Report


    Adjust                           Agree any change in scope in writing before doing it                       04 Change Order


    Check                            Run every deliverable through the review before it goes out                15 Deliverable Review Checklist



Discipline: weekly status, an up-to-date RAID log, and nothing leaving without the review checklist.




Stage 4: Close it out

Leave the client with everything they were promised, and a clean record behind.


    STEP                      DO THIS                                                                                              TEMPLATE


    Package                   Deliver all recordings, templates and materials to the agreed location                               19 Documentation SOP


    Invoice                   Issue the final invoice                                                                              05 Invoice, 20 Billing SOP


    Hand over                 Make sure the client can use what they have without you                                              25 (this guide)


    Record                    File a one-paragraph engagement summary so the next person understands it in two minutes             19 Documentation SOP




The standards that run through all four stages

These apply the whole way through, not at a single stage.

        Communication: acknowledge fast, confirm decisions in writing, never go dark. (18 Client Communication SOP)

        Capacity: only book what the practice can deliver well. (17 Scheduling and Capacity SOP)

        Confidentiality: handle client information and AI tools responsibly, every time. (21 Compliance, 24 Client-Sensitive Information)

        Quality: nothing reaches a client without the review checklist. (15 Deliverable Review Checklist)

        Speed with judgement: use the prompt library to move faster, and own every output. (23 Starter Prompt Library)




If you are new to the practice

Read in this order: 06 Client Intake SOP, 08 Discovery Questionnaire, 15 Deliverable Review Checklist, 23 Starter Prompt Library. Those four
plus this guide give you enough to be useful on your first engagement.
