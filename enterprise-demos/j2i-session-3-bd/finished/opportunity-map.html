Recommended first step

One recommendation

Start with opportunity 1, the compliance matrix, aimed at the draft solicitation expected in December. It needs only the solicitation itself, so it does not wait on gathering past performance files. Every row can be checked against a page reference, so it fits your rule that nothing invented reaches a contracting officer. Past performance (opportunity 2) follows once the files are in one place.
