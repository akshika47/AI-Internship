# 4-Day Challenge: Build an MCP App (and find out if MCP is dead)

Code for the TAI Labs community challenge, 26 to 29 October 2026. Each day has its own folder with a README you
can follow step by step.

An **MCP App** is an MCP tool whose result opens a small interactive page right inside the chat, in Claude,
ChatGPT and other hosts. You click in it, and Claude knows what you clicked. The pattern for the week:
Claude suggests, you decide in the app.

## The four days

| Day | Goal | You're done when | Folder |
|---|---|---|---|
| 1 | Is MCP dead? Read both sides, then try a real MCP server in Claude | You've asked Claude a question it answered with a connector | [`day-1/`](day-1/) |
| 2 | Your first MCP App, on demo shop data | You've seen the chart in Claude, run it on your laptop and watched your click reach the model | [`day-2/`](day-2/) |
| 3 | Claude suggests, you decide: your own CSV, and buttons that change it | Your CSV is in the app with Claude's suggestions, and you've approved or skipped a row | [`day-3/`](day-3/) |
| 4 | Put it in Claude, check it's safe, and show us | Coming soon | |

## What you need

A Claude account (Free works: it allows one custom connector), Node.js 20.19 or newer, and git. No API key:
nothing in this folder calls a model or costs money.
