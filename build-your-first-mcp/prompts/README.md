# Prompt pack

Copy one file at a time into your AI assistant. Each one builds on the last.

| File | When |
|---|---|
| [`1-build-first-tool.md`](1-build-first-tool.md) | Stage 1: your first tool, in a new chat |
| [`2-add-more-tools.md`](2-add-more-tools.md) | Stage 2: more tools and one that writes, same chat |
| [`3-add-weekly-review.md`](3-add-weekly-review.md) | Stage 3: a ready-made weekly review, same chat |
| [`ask-your-server.md`](ask-your-server.md) | Once it's connected: questions to try, with the answers you should see |
| [`claude-code.md`](claude-code.md) | Using Claude Code? Start here instead of stage 1 |

The technical rules inside each prompt (the exact FastMCP import, fixed SQL, no `print()`, the full database path) prevent the most common errors. Keep them as they are.
